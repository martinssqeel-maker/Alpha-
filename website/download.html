Desktop app

Download Alpha AI Workspace

The Windows installer is downloaded from your account area, so the release and its checksum are only handed to signed-in accounts.

Sign in to get the installer

Create an Alpha account with an email address and a password, or continue with GitHub or Google, and the download appears in your account area. The desktop app signs in with that same account.

Create an account Sign in

Already signed in in this browser? You will be taken to your downloads automatically. Current release: latest.

Before you install

  • Windows 10 or 11 (x64)
  • Per-user install, no administrator rights
  • ~400 MB of disk after install

After you install

  • Install Ollama for local models
  • Or add a cloud provider API key in the app
  • Open a project folder and start working

Need help?

  • The installer is unsigned — choose More info → Run anyway if SmartScreen warns
  • Releases and changelogs are on GitHub
