About

A workspace that asks before it acts

Alpha AI Workspace is an independently built, MIT-licensed desktop environment for working with AI on your own machine. It is not a model, and it does not train on your work: it is the place where you run models — local or hosted — against real projects, with permissions you set and a record of what happened.

◆

Why it exists

Most AI coding tools assume a hosted service and a credit card. Many people have a machine that can run a capable model locally, or want to choose exactly which provider sees their code. Alpha exists so that running a good local model and choosing a hosted one are the same workflow, not two different products.

⛨

What it will not do

It will not silently send a local conversation to a cloud provider, push to a remote behind your back, escalate its own permissions, or treat a document you attached as an instruction. Those constraints are enforced in the product, not described in a policy.

◈

How it handles money

Shared cloud inference is metered against an allowance that is checked before a request runs and settled against the provider's real token count afterwards. Estimates are labelled as estimates; costs the provider reports are used as they are reported.

Under the surface

What it runs on

Stated plainly, because it tells you what you can expect to maintain.

▤

Desktop application

An Electron application for Windows 10 and 11 (x64) with a React interface, a process-isolated preload bridge, and a local database. It stores its own settings and conversations on your machine, and ships automatic updates through signed releases.

☁

Account and AI service

A small HTTP API running as a serverless function against a Postgres database. It owns accounts, sessions, plan entitlements, usage counters and the AI gateway. No provider credential is ever stored in, or sent to, the desktop client.

▣

This website

Plain HTML, CSS and JavaScript with no build step and no tracking scripts — the pages you are reading are the files in the repository.

Support

Getting help

⑂

Issues and source

Development happens in the open on GitHub. Bug reports, questions and feature requests belong in the issue tracker, where they can be searched and answered publicly.

✉

Account problems

Sign-in problems, a suspended account, or a usage figure you believe is wrong: an administrator can see your account's sessions, plan, entitlements and audit history, and can adjust an allowance without reading your conversations.
