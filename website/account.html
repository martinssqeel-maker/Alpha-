Install it

  1. Download the installer above (it is free and unsigned — if SmartScreen warns, choose More info → Run anyway).
  2. Install Ollama if you want to run models locally.
  3. Open Alpha, sign in with this same account, and install a model from the Models page.

System requirements

  • Windows 10 or 11 (x64)
  • Per-user install — no administrator rights required
  • Roughly 400 MB of disk after install
  • Ollama for local models, or an API key for a cloud provider

Your account details and installer link stay behind the server's own session check — this page never receives a provider token.

Need the app? It is in the Downloads section of this account area once you are signed in.
