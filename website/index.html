Capabilities

Everything a serious AI coding session needs

A real workspace, not a chat box — with safety rails you control.

◆

Bring your own models

Manages your local Ollama models from inside the app — browse, install with live progress, and remove — and supports any OpenAI-compatible endpoint: OpenAI, OpenRouter, Groq, DeepSeek, Together, LM Studio, custom.

⛨

Agentic, but safe

Chat / Assist / Agent modes with per-capability allow / ask / deny levels gate every write, delete, command, install, network call, commit, and push.

✓

Approvals you control

Risky actions surface an approval dialog and only run once you accept. Nothing mutates silently.

⌘

Project-aware

File access is confined to the opened project root. Path traversal and symlink escapes are blocked; sensitive files are denied by default.

≡

Real editing

Unified diffs, checkpoint/restore, atomic writes, and stale-file conflict detection — review before you apply.

⑂

Integrated Git & GitHub

Status, diff, stage, commit, branch, push/pull — never a force-push. Browse and create GitHub repos without leaving the app.

▸

Streaming terminal

Run dev commands with live output, real cancellation and risk assessment. Destructive commands demand explicit approval.

✎

Attachments & voice

Drop in text, images, and PDFs; dictate prompts via a configured transcription provider, and hear replies read aloud.

FAQ

Questions, answered

Is my code or data sent anywhere?

Only if you choose a cloud model — then your prompts go to that provider. With local Ollama, nothing leaves your machine. File access is confined to the project you open, secrets are OS-encrypted, and logs are redacted.

Do I need an account?

Yes — the Windows installer is downloaded from your account area, so you create an Alpha account first. Once installed, the app itself works offline with local Ollama models; the account is what gets you the installer and keeps your app sign-in in sync.

Which models are supported?

Anything Ollama can serve, plus any OpenAI-compatible endpoint. Tool-calling and vision are detected per model and surfaced as capability badges, and the Models page recommends sizes that fit your machine's memory.

Why does Windows warn on install?

The installer is currently unsigned, so SmartScreen flags unknown publishers. Click More info → Run anyway. Code signing is on the roadmap.

Does it update itself?

Yes — packaged builds check GitHub Releases a few seconds after launch and can update from Settings → Updates.

Is it free?

Yes — the current build is free and MIT-licensed. The core local-first experience stays that way.
